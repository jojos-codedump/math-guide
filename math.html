01 · Sequence
Follow phases 0 → 12 in order. Every topic is a prerequisite for what follows. The phase nav is for reference and review — not for skipping ahead.
02 · Books
Read primary books cover-to-cover. Use supplementary books for depth on specific chapters and for extra problem sets. Never buy both — choose one.
03 · Projects
◆ coding projects are implementation milestones. ◈ proof milestones are written proofs on paper. Both are required — doing only code produces a practitioner, not a mathematician.
04 · Review Cycles
Review notes (in phase banners, highlighted in blue) are mandatory. Return to the cited phase before advancing. Long roadmaps without review produce knowledge that decays before it can be applied.
05 · PDF Labels
Author · legally free = official open release. Widely found via search = university mirrors; not an official release. Purchase recommended = no consistent free version exists.
