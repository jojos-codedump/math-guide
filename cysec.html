Gap Analysis — What Your Collection Is Missing
!Critical: Windows & Active Directory — zero coverage. No Windows internals, no AD exploitation, no PowerShell for attack. This is the single biggest gap; AD compromise is the core of nearly every enterprise pentest.
!Critical: DFIR & Memory Forensics — Blue Team Handbook exists but no dedicated incident response or memory forensics book. The Art of Memory Forensics (Ligh et al.) is the canonical text and is absent.
!Critical: Assembly Language — Hacking: Art of Exploitation touches x86 assembly but there is no dedicated primer. Binary exploitation is impossible without this foundation.
!Major: C Programming Basics — Secure Coding in C assumes you already know C. No introductory C book in the collection.
!Major: Python Basics — Black Hat Python assumes Python fluency. No introductory Python book in the collection.
!Major: Wireless Security — No dedicated 802.11 / WiFi attack book. A significant vector with no coverage.
!Major: Container & Kubernetes Security — Cloud security is partially covered (AWS) but Docker/K8s attack and defence has zero coverage.
~Minor: Mobile Security — No Android or iOS pentesting coverage. OSINT has partial coverage via Operator Handbook but no dedicated text.
