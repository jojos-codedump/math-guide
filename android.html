💡

The honest ceiling isn't the stack — it's the backend. This roadmap makes you a complete Android developer. Firebase and Supabase (covered in Phase 7) handle the backend for most app ideas without writing any server code.

Outside this roadmap
Wear OS / Android TV
Platform-specific form factors — separate path.
Game development
Unity or Godot — a completely different discipline.
Bluetooth / IoT
Hardware integration requires additional specialist knowledge.
Kotlin Multiplatform
KMP / Compose Multiplatform is a natural extension layer after this roadmap.
Flutter
Separate framework, Dart language, different mental model entirely.
Advanced DSP / Audio
Signal processing and low-level media work is a niche specialty.
Roadmap

All 8 phases, in sequence

Each phase has three tabs: Topics to learn, Watch Order with exact videos/playlists, and Tools & Links. Follow them in order.

⚠️

The most common beginner mistake is jumping to Compose before Kotlin is solid. Give Phase 1 its full time. Null safety, lambdas, coroutines, and sealed classes in Phase 4 all require a strong Kotlin foundation.
