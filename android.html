After Phase 9, the natural extension is either KMP/Compose Multiplatform for cross-platform work, or backend Kotlin (Ktor/Spring) for full-stack mobile development.

01 · Strict sequence
Follow phases 0 → 9 in order. Every phase is a dependency for the next. The phase nav is for review — not skipping. Phase 2 (Android Platform) must come before any Compose work; the Coroutines Primer in Phase 3 must come before Phase 4's async APIs.
02 · Watch order
Videos are listed in sequential watch order per topic. Watch them in the order given — later videos assume the earlier ones. Multiple playlists per topic are deliberate: comprehension over fast completion.
03 · Books
Read primary book sections alongside each topic. PDF labels: Author free = official open release. Widely found = circulates on university mirrors. Purchase recommended = no consistent free copy exists.
04 · Build milestones
◆ Build Milestones require a working, running app. ◈ Practice Drills are focused code exercises. Both are required — watching without building produces someone who can follow along, not someone who can build independently.
05 · Review cycles
Blue banners at phase tops are mandatory review obligations — return to the cited phase before advancing. These are not optional reading; they are the mechanism by which knowledge becomes durable.
06 · Mastery checks
Every topic ends with ? Mastery Check questions. Answer each one out loud, without notes. If you cannot answer fluently, re-read the topic before proceeding. Then repeat at 1 week and 1 month — open the project and add a feature using only the official docs.
